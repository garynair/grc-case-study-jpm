# Answer Key — JPMorgan Chase 2014

> **Learners:** finish each task on your own before opening its model answer. The value of the simulation is in working through the judgment calls yourself. Reading the answers first skips the part that teaches.

The model answers show one strong way to meet each task's required outputs, not the only acceptable answer. Grade on whether the required elements are present and the reasoning is supported by the case. Don't test technical configuration details; grade ownership, scope, evidence, risk, control intent, escalation and management decisions.

**Running this as a graded course?** Copy the repository and remove this folder from the learners' copy. The license allows it.
