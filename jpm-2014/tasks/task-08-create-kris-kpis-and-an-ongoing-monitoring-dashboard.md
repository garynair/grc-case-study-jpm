# Task 8: Create KRIs, KPIs and an Ongoing Monitoring Dashboard

**Suggested time:** 90 minutes · **Primary lead:** GRC Reporting Analyst

> **Required outputs**
>
> KPI/KRI catalog; dashboard; thresholds; reporting and escalation schedule.

## Why this task matters

Management needs measures that reveal both whether controls are working and whether risk is increasing.

## Learning objectives

- Distinguish KPIs from KRIs.
- Create measurable coverage and exception indicators.
- Define thresholds and escalation actions.

## Action items

1. Create at least four KPIs and four KRIs.
2. Define calculation, target, threshold, owner and reporting frequency.
3. Build a one-page red-amber-green dashboard.
4. Define escalation rules for overdue critical exceptions.
5. Identify evidence sources for each metric.

## Questions to answer

- Why is 'number of security tools' a weak measure of control effectiveness?
- Which metric best tests asset-inventory completeness?
- Which metric warns that exception risk is increasing?
- What should happen when a critical threshold is breached?
