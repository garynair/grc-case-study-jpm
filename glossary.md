# Beginner Glossary


| **Term** | **Plain-language meaning** |
|---|---|
| Asset | Anything the organization needs to protect, such as a server, application, database, user account or network device. |
| Server | A computer that provides a service, hosts an application or stores data for other computers. |
| Microsite | A small website created for a specific campaign, event or purpose. |
| MFA / 2FA | Multi-factor or two-factor authentication. A user must provide more than a password, such as a phone approval or security token. |
| Vulnerability | A weakness that could be used to gain unauthorized access or cause harm. |
| Control | A policy, process or technology used to reduce risk. |
| Control exception | A known situation where a required control is not fully applied. |
| Compensating control | A temporary or alternative safeguard used while the required control is unavailable. |
| Asset inventory | The official list of systems, applications, devices and owners. |
| Lateral movement | When an attacker moves from the first compromised system to other internal systems. |
| Network segmentation | Separating systems into zones so that a compromise in one area does not automatically reach another. |
| Risk | The possibility that an event will affect objectives. A useful risk statement includes cause, event and impact. |
| Likelihood | How probable the event is. |
| Impact | How serious the consequences would be. |
| Inherent risk | Risk before considering controls. |
| Residual risk | Risk remaining after controls and corrective actions. |
| Risk owner | The person accountable for deciding and overseeing how a risk is handled. |
| KPI | Key Performance Indicator. Measures whether a process is performing as intended. |
| KRI | Key Risk Indicator. Warns that risk exposure may be increasing. |
| SIEM | A security monitoring system that collects logs and alerts analysts to unusual activity. |
