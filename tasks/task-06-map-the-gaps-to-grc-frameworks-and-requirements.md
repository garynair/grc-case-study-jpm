# Task 6: Map the Gaps to GRC Frameworks and Requirements

**Suggested time:** 90 minutes · **Primary lead:** Compliance and Controls Analyst

> **Required outputs**
>
> NIST CSF gap map; simplified regulatory mapping; evidence list; compliance conclusion.

## Why this task matters

Framework mapping connects a real event to expected governance and control practices. Beginners should focus on the purpose of each requirement rather than memorizing control numbers.

## Learning objectives

- Use NIST CSF functions to organize gaps.
- Explain the relevance of FFIEC, GLBA, OCC and SEC requirements in plain English.
- Identify evidence needed to prove control operation.

## Action items

1. Map case facts to Identify, Protect, Detect, Respond and Recover.
2. Mark each function Effective, Adequate, Partial or Gap and explain why.
3. Map at least four regulatory or standards requirements to the case.
4. List evidence an auditor would request.
5. Write a one-paragraph compliance conclusion.

## Questions to answer

- Which NIST CSF functions were weakest?
- Which functions worked relatively well after detection?
- Why does a framework mapping require evidence rather than only a written policy?
- How would current SEC disclosure expectations differ from 2014 practice?
