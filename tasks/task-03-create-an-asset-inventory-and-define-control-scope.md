# Task 3: Create an Asset Inventory and Define Control Scope

**Suggested time:** 90 minutes · **Primary lead:** Asset and Control Analyst

> **Required outputs**
>
> Simplified asset inventory; ownership gaps; control-scope statement; inventory completeness checks.

## Why this task matters

Controls cannot protect assets that are missing from the official inventory or outside the stated scope.

## Learning objectives

- Identify systems, data, owners and connections.
- Explain why internet-facing and business-managed systems remain in security scope.
- Propose simple checks that confirm the inventory is complete.

## Action items

1. Create an inventory of at least six assets mentioned or implied in the case.
2. Record business owner, technical owner, data handled, internet exposure, criticality and applicable controls.
3. Mark the asset that was omitted from the MFA program.
4. Write a control-scope statement for MFA and vulnerability management.
5. Propose four inventory completeness checks.

## Questions to answer

- Why was the Corporate Challenge server easy to miss?
- Who should be accountable for registering a new microsite?
- Does a low-business-criticality website still require strong security controls?
- How can the organization test whether the inventory is complete?
